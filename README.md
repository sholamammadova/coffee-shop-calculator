
# ☕ Coffee Shop Calculator

## 📌 Project Overview

A Python-based coffee shop order management project
developed through five progressive sprints.

The project demonstrates fundamental Python programming
concepts through a practical business scenario involving
coffee shop orders and price calculations.

## 🎯 Project Objectives

- Apply fundamental Python programming concepts.
- Develop practical problem-solving skills.
- Simulate a coffee shop ordering process.
- Improve code organization and readability.
- Develop a solution through incremental improvements.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- GitHub

## 📂 Project Structure

coffee-shop-calculator/
- coffee_shop_calculator.ipynb
- README.md

## 🚀 Development Approach

The project is organized into five progressive sprints,
demonstrating the step-by-step development of a
Python-based coffee shop calculator.

## ▶️ How to Run

1. Clone or download this repository.
2. Open `coffee_shop_calculator.ipynb`
   using Jupyter Notebook or Google Colab.
3. Run the notebook cells sequentially.
4. Follow the instructions provided in the notebook.
